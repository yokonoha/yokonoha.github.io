*.fswriteprj (拡張子 / File Extension)とは?

拡張子 fswriteprj は、ウェブサイト作成ツール 「FSWrite Web」のプロジェクトファイルである。


FSWrite Webのロゴマーク

概要

fswriteprjファイルは、FSWrite Webのプロジェクトファイルエクスポート機能及び付属の復元ツールにて出力されるファイルであり、Plain Textで記述されている。エクスポートされたfswriteprjファイルはFSWrite Webへインポートが可能であり、他のデバイスでもワークスペースの設定状態をそのまま引き継いで作業を続行できる。

ファイル構造

{ "previewCollapsed": "0", "fswrite_save_enabled": "true", "fswrite_state": "{\"txtPageTitle\":\"*.fswriteprj (拡張子 / File Extension)とは? 横葉ノート事典 - 横茶横葉のサイト\",...." }
ファイル構造のサンプルデータ

ファイルの内容はFSWriteの各種設定の状態やWebページのコンテンツデータを含むJSON形式テキストであり、FSWrite WebのLocalStorageをバックアップしたものである。

FSWrite Web Rev.6.2.1において、fswriteprjファイルはリアルタイムプレビューパネルを表示するか折りたたむかを記録したエントリであるpreviewCollapsed(int)から記載されており、総エントリ数は3である。

バージョン間の差異

FSWrite Webにおいてfswriteprjファイルのエクスポート機能はRev.6.0.0より実装された。そのため、6.0.0以前のバージョンとの互換性はない。しかし、Rev.6.0.0以降の後方互換性があり、Rev6.0.0にて作成したファイルはRev6.2.1などの後発バージョンでも正常に取り込むことができる。

データの書き換え

fswriteprjファイルはプレーンなJSONファイルであることからコードエディタ等による編集が可能である。しかし、予期せぬ動作を防ぐため、編集は推奨されていない。
